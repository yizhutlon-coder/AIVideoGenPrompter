# Guided-first checkpoint review — 2026-09-23

This branch preserves the guided-first draft and the preceding app, security, research, and test work. It is a review checkpoint, not a release. The main app remains at the repository root; the guided-first draft is in `guided-first-preview/`.

## Resolve before promoting the preview

1. **ComfyUI access:** The workflow export dialog mentions `--enable-cors-header` for automatic model-list discovery. With no origin argument, ComfyUI allows all origins and changes its origin protection. Keep the copy/paste path; remove the suggestion to widen access for this convenience. See `PromptStudio.html` near `wfMdlFetch()` and the same dialog in the preview.
2. **Privacy wording:** The preview starts only its page server and uses any Ollama service already running. Its "offline & ready" label cannot verify that service's cloud configuration. Align the launcher and wording with the actual boundary. See `guided-first-preview/Start-Guided-Preview.ps1` and its setup/status text.
3. **Unfinished guided drafts:** `guided-first-preview/tools/WalkThrough.html` does not save fields. A refresh loses long H3 forms. Add explicit local draft saving and clearing, with a visible storage explanation.

## Usability and safety follow-ups

- Make setup explain that Ollama and the downloaded Qwen model power optional prompt assistance, not image/video generation. Match the README's first-run steps to what each launcher actually does, including the required relaunch after installing Ollama.
- Pasting a model link currently starts a pull. Make download an explicit button action, provide cancellation, check HTTP results, and say that model removal affects Ollama's shared model library. The regular launchers forcibly restart Ollama and can interrupt other apps; disclose or redesign this behavior.
- Add one privacy panel describing history, pins, context, H3 autosaves, tutor chat, browser storage, and plaintext exports, plus an explicit erase action with a clear scope.
- Associate repeated guided-form labels with their inputs and give icon-only buttons accessible names. Keep output checks described as known checks, not a guarantee of factual fidelity.
- Complex H3 AI setup remains model-dependent; the app safely rejects invalid drafts, but the guided/direct deterministic paths should remain prominent.

### 2.3 The six system prompts — verbatim extracts

The file defines **six system prompts** via a `SYSTEM_PROMPT_TYPES` dict keyed by a 3-bit
flag: `(multi_images << 2) | (is_vl << 1) | zh`. The prompts are:

#### 2.3a LM_ZH_SYS_PROMPT (text-only, Chinese output)

```
你是一位Prompt优化师，旨在将用户输入改写为优质Prompt，使其更完整、更具表现力，同时不改变原意。
任务要求：
1. 对于过于简短的用户输入，在不改变原意前提下，合理推断并补充细节，使得画面更加完整好看；
2. 完善用户描述中出现的主体特征（如外貌、表情，数量、种族、姿态等）、画面风格、空间关系、镜头景别；
3. 整体中文输出，保留引号、书名号中原文以及重要的输入信息，不要改写；
4. Prompt应匹配符合用户意图且精准细分的风格描述。如果用户未指定，则根据画面选择最恰当的风格，或使用纪实摄影风格。如果用户未指定，除非画面非常适合，否则不要使用插画风格。如果用户指定插画风格，则生成插画风格；
5. 如果Prompt是古诗词，应该在生成的Prompt中强调中国古典元素，避免出现西方、现代、外国场景；
6. 你需要强调输入中的运动信息和不同的镜头运镜；
7. 你的输出应当带有自然运动属性，需要根据描述主体目标类别增加这个目标的自然动作，描述尽可能用简单直接的动词；
8. 改写后的prompt字数控制在80-100字左右
```

Key points for corpus: default style is **纪实摄影 (documentary photography)**, avoid 插画
(illustration) unless explicitly requested or the scene strongly suits it. Ancient poetry
triggers Chinese-classical-only framing. 80–100 character target.

#### 2.3b LM_EN_SYS_PROMPT (text-only, English output)

Parallel to ZH but targets English output. Same structure, same 80–100 word target.
Notable difference: no ancient-poetry rule (rule 5 in ZH is absent in EN).

#### 2.3c VL_ZH_SYS_PROMPT (image+text → Chinese, single image)

Adds two rules vs LM_ZH:
- Rule 8: "你需要尽可能的参考图片的细节信息，如人物动作、服装、背景等"
- Rule 9: word count 80–100
- Rule 10: "无论用户输入什么语言，你都必须输出中文"
- Rule 4 changed: style inferred from **photo** style if not specified (not defaulting to documentary)

#### 2.3d VL_EN_SYS_PROMPT (image+text → English, single image)

Mirror of VL_ZH but outputs English. Rule 10: "always output in English."
**Bug preserved from Wan2.1**: Rule 3 still says "The overall output should be in Chinese"
despite this being the English-output variant — a known issue per GitHub Issue #186 and #452.

#### 2.3e VL_ZH_SYS_PROMPT_FOR_MULTI_IMAGES (first+last frame → Chinese)

For first-frame/last-frame I2V. Adds:
- Rule 1: "用户会输入两张图片，第一张是视频的第一帧，第二张是视频的最后一帧"
- Rule 10: emphasize inter-frame transitions ("走进", "出现", "变身成", "镜头左移" etc.)
- Rule 11: always Chinese output
- Rule 12: 80–100 characters

#### 2.3f VL_EN_SYS_PROMPT_FOR_MULTI_IMAGES (first+last frame → English)

English parallel of multi-images. Adds Rule 10 about potential changes between frames.

### 2.4 System prompt dispatch logic

```python
SYSTEM_PROMPT_TYPES = {
    int(b'000', 2): LM_EN_SYS_PROMPT,     # 0: text-only, English
    int(b'001', 2): LM_ZH_SYS_PROMPT,     # 1: text-only, Chinese
    int(b'010', 2): VL_EN_SYS_PROMPT,     # 2: image+text, English
    int(b'011', 2): VL_ZH_SYS_PROMPT,     # 3: image+text, Chinese
    int(b'110', 2): VL_EN_SYS_PROMPT_FOR_MULTI_IMAGES,  # 6: multi-img, English
    int(b'111', 2): VL_ZH_SYS_PROMPT_FOR_MULTI_IMAGES   # 7: multi-img, Chinese
}
```

`decide_system_prompt(tar_lang, multi_images_input)` computes:
`task_type = zh + (is_vl << 1) + (multi_images_input << 2)`

This means `tar_lang="zh"` sets bit 0, `is_vl=True` sets bit 1, and multi-image sets bit 2.

### 2.5 Supported LLM backends

Two backends:
- **DashScopePromptExpander**: uses Alibaba's DashScope API (default models: `qwen-plus` for
  text, `qwen-vl-max` for image+text). Requires `DASH_API_KEY`.
- **QwenPromptExpander**: local inference using HuggingFace models. Default: `Qwen2.5-14B-Instruct`
  for text, `Qwen2.5-VL-7B-Instruct` for image+text. Also supports 3B and AWQ variants.

### 2.6 Corpus implications

This resolves a standing gap. The system prompts reveal:
1. **Default documentary-photography style** — if our prompt studio doesn't specify a style and
   the user also doesn't, the extend system will default to documentary, not cinematic/anime.
2. **The 80–100 word target** — extended prompts from the official system will be compact.
3. **Chinese-classical gating** — ancient poetry input triggers a hard constraint against
   Western/modern elements.
4. **The VL_EN bug** — Rule 3 contradicts Rule 10 in the English VL prompt. Users running
   the English VL path may get Chinese-contaminated extensions.

## Contradicts our current guidance

1. **"SCAIL-2 / Wan-Animate are prompt-inert."** 🔴 **Retract the absolute claim.** Vendor README
   (`github.com/zai-org/SCAIL-2/blob/wan-scail2/README.md`) has a **Prompt Semantics** section, an official
   enhancer, and states `[OFFICIAL]`: *"SCAIL-2 is trained with long, detailed prompts"* and *"--prompt
   should describe the generated video itself. It should not be an instruction to the model."* New vendor
   rule we lack: **for replacement mode, describe the scene as if the swap already happened.** Replace
   with "prompt-*sensitive* but low-leverage relative to mask/driving inputs" — we have no `[TESTED]`
   evidence for the converse magnitude. **Two runs of zero coverage were caused by our own brief:** GitHub
   has no `main`, but **HF `/blob/main/` resolves.**
2. **"Front-load the subject."** 🔴 **Scope per family.** Wan 2.2's own rewriter example and every 电影美学
   example in the 09-02 docs lead with **9–11 aesthetic tags before the subject** — 「中焦距，柔光，低对比度，
   边缘光，低角度拍摄…镜头仰拍拍摄外国男子…」 `[OFFICIAL]`. Agent B found **three independent surfaces
   confirming subject-first** for Krea 2, Z-Image Turbo and SCAIL-2 (whose official examples are all
   subject-first `[OFFICIAL]`). Both agents are right about different families. Wan 2.2's convention is
   `[style] → [aesthetic tags] → [subject + scene + motion]`; Krea 2 puts its style trigger **last**
   (`"A deer grazing in the forest, vintage tarot style"` `[OFFICIAL]`). **No portable style-position rule
   exists.** Tag order *within* Wan's leading block varies across examples, so that block is an unordered
   set — "order carries emphasis" may survive inside the prose clause.
3. **"Write one flowing prose paragraph"** — 🔴 contradicted **for LTX-2.5, by the vendor.** `[STAFF]`
   `art-alex` (`LTX.io org`), `Lightricks/LTX-2.5/discussions/62`, ≈09-04, fixed a failing prompt with
   "very minor changes": deleted the tag preamble, deleted the quality tail, deleted the camera line
   (`A cinematic top-down overhead shot`), **broke the paragraph into one chronological beat per line**,
   added an **establishing state** ("parked at the side of the road **when suddenly**"), added spatial
   specificity ("from the left", "driver seat"). Independently corroborated `[LORE]`: *"You just have to
   FORGET! the idea everything has to be in 'one flowing paragraph'."* Prose-not-tags survives;
   **single-paragraph packaging does not.** Note the vendor also silently dropped "cinematic" — our
   Wan-only rule may be wider.
4. **"Write prose because the encoder is an LLM"** — 🟠 moved **both ways**, stays contested. *For:*
   MiniMax states 「它用完整的多模态语言模型读你的提示词」 `[OFFICIAL]`; H3's encoder is Qwen3-VL-32B.
   *Against:* arXiv:**2609.11242** (Kling/Kuaishou, ECCV 2026) finds leading models *"consistently fail on
   logic-heavy and rule-constrained tasks"* and fixes it by offloading reasoning to a **separate** VLM — an
   LLM encoder does not reason. And `[LORE]` on two models **sharing the Qwen3 encoder family**: Z-Image
   Turbo wants **100–180 words** and is "genuinely confused" by short prompts; Krea 2 is fine at **5–20**.
   *Same encoder family, opposite length appetite* — the **training recipe** sets prompt style, not the
   encoder class. Sharpest formulation yet; import it.
5. **"Quality-suffix tags are retired"** — 🟠 soften to model-scoped. The most-read Civitai ZIT/Krea guide
   recommends *"then a short quality tail if needed"* for Z-Image Turbo `[LORE]`, no seeds. Flag ZIT as
   the exception to test. Counter-pressure: Lightricks' own fix (item 3) **begins by deleting** the tail.
6. **"Expansion helps only when underspecified"** — 🟠 add a **duration clause**. `[LORE]` an enhancer
   tuned for 5–10 s one-shots under-fills a 40 s request: *"If it has not enough to do for the video
   length, it freaks out completely."* arXiv:2609.11242's rewriter targets **"concise, constraint-aware"**
   prompts — a major lab arguing the useful rewrite *shortens toward constraints*.
7. **"LTX negatives are inert"** — ✅ **generalise, don't scope.** Four independent confirmations: Krea 2
   Turbo ships `guidance 0.0` `[OFFICIAL]`; H3-World runs `--cfg-scale 1.0` `[OFFICIAL]`; SCAIL-2's
   distilled recipe is `--sample_guide_scale 1.0` `[OFFICIAL]`; ZIT "effectively ignores negative prompts"
   at low CFG `[LORE]`. Teach **CFG≈1 ⇒ negatives inert** as physics, not an LTX quirk.
8. **"One camera verb per shot, placed first"** — 🟢 keep as *default*, note the exception: `复合运镜` is an
   official named category whose example chains two moves. `[OFFICIAL]`
9. **"H3 local = 768p"** — add one word: **768p short edge** (「768p 短边」). `[OFFICIAL]`
10. **v0.34.x verification jobs: both pass, with corrections.** The ComfyUI identifier is **`taeh3`**
    (PR #15695), not "TAESD-H3" — don't invent the name. `embedding:` syntax is now `[STAFF]`-confirmed by
    Comfy Org's `Lexius` on `Comfy-Org/MiniMax-H3#50`: *"invoke them in the CLIPTextEncode node like this
    (you can omit the .pt extension): embedding:embedding_filename.pt."* First structured non-prose token
    in a video prompt in our scope — ComfyUI-specific, does not travel to `diffusers`.

**🚨 Quarantine flag.** `[LORE]`, vendor silent: a user reports Lightricks uploaded a **mismatched LTX-2.5
text-encoder checkpoint** (commit `1b92891`) — *"not synchronized with the video model, resulting in
artifacts and really weird prompt following"* — independently noticed by a second user. **A second
confounder stacked on the enhancer confound.** Date that commit and quarantine LTX-2.5 verdicts after it.
Related: the enhancer can confound by *emptying*, *contaminating with stale state*, or *corrupting into
noise*, not just by improving. Free diagnostic: **put a preview-text node on the enhancer output and read
what actually reached the encoder.**

**One more failure mode:** `[LORE]` ComfyUI's stock KSampler reads **CFG 0.0 as pure unconditional
output**, so Krea 2's official `guidance 0.0` silently ignores the prompt — *"use CFG 1.0 instead."* The
user sees "the model ignored my prompt" and blames the prompt.

**Five corpus-relevant findings** (all `[OFFICIAL]`):

1. **Default style is 纪实摄影 (documentary photography)**, not cinematic. Rule 4 (ZH): 「如果用户
   未指定，则根据画面选择最恰当的风格，或使用纪实摄影风格。如果用户未指定，除非画面非常适合，否则不要
   使用插画风格。」 The VL variants change this to infer style from the **photo** instead.

2. **80–100 character/word target.** Rule 8 (ZH): 「改写后的prompt字数控制在80-100字左右」. This is
   tighter than the corpus's current "60–200 character cinematic expansion" range for T2V.

3. **Ancient-poetry gating.** Rule 5 (ZH only; absent in EN): 「如果Prompt是古诗词，应该在生成的
   Prompt中强调中国古典元素，避免出现西方、现代、外国场景。」 A hard constraint with no EN parallel.

4. **VL_EN bug: Rule 3 contradicts Rule 10.** The English VL prompt's Rule 3 says "The overall
   output should be in Chinese" while Rule 10 says "always output in English." Known issue per
   GitHub Issues #186 and #452. Users on the English VL path may get Chinese-contaminated outputs.

5. **Two backends.** DashScope API (`qwen-plus` / `qwen-vl-max`) and local HuggingFace
   (`Qwen2.5-14B-Instruct` / `Qwen2.5-VL-7B-Instruct`). The local backend uses smaller models
   than the API path.

## Contradicts our current guidance

1. 🟠 **"Cinematic expansion" is the wrong default style for Wan's extender.** The official system
   prompt defaults to **纪实摄影 (documentary photography)** when no style is specified. The corpus's
   INDEX.md says *"T2V wants a richer 60–200-character cinematic expansion"* — the word "cinematic"
   is ours, not the vendor's. **Amend to "documentary-photography expansion" or remove the style
   word entirely** and let the system prompt's own logic apply.

2. 🟠 **"60–200 characters" is wider than the vendor targets.** The official system prompt targets
   **80–100 characters/words**. The corpus's range was derived from the 电影美学 constants (which
   are the *model's* system prompt, separate from the *extender's* system prompt). These are two
   different prompts acting at two different stages. **Teach the distinction:** the extender's
   output (80–100) feeds into the model, whose own system prompt then applies the 电影美学 framing.

3. 🟢 **"CFG≈1 ⇒ negatives inert" strengthened again.** Three H3 distillation projects now confirm
   it, with ModelTC's docs providing the clearest formulation: guidance-free distillation makes
   raised CFG *fight* the distillation. The per-path rule from the 09-17 digest holds and now has
   three more rows of evidence.

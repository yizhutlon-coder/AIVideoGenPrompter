🧵 Clip Stitcher

Chain generated clips into one long video. Everything stays on your machine — this page prepares exact ffmpeg commands; ffmpeg does the lossless work.

The chaining workflow (why the cuts are invisible)

  1. Generate clip 1 (any model).
  2. Drop it here → 📸 Last frame → you get a PNG of its final frame.
  3. Use that PNG as the start / reference image of the next generation (Wan I2V, LTX I2V, H3 image ref…). Prompt Studio's I2V dialects describe motion from this frame — exactly what you want.
  4. Drop clip 2 here too. Repeat.
  5. When done, copy the stitch command below. Because each clip starts on the previous clip's last frame, the tool drops that duplicated frame at every seam — the cut lands on identical pixels and is invisible.
Honest caveat: chained I2V drifts slightly in color/sharpness over many hops — that is the model re-encoding reality each time, not a stitching problem. Frame-exact reference PNGs (not screenshots) keep it minimal; some people re-grade the final video once at the end.

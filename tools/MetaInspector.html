🔎 Meta Inspector

Every ComfyUI output carries its own recipe — the exact prompt, model files, LoRAs, seed and sampler, plus the whole node graph. Drop one here to read it. Nothing is uploaded; the file is parsed inside this page.

What it is for
  • "Which one worked?" After a big batch, drop the keepers here. Each file names its own seed, prompt, steps, CFG, sampler and LoRA strengths — compare two outputs side by side and you can see what actually changed between a hit and a miss, instead of guessing from memory.
  • Recreate or edit a success. Download the workflow and drag it onto ComfyUI, or use Reload settings into workflow export to reopen it in Prompt Studio with everything pre-filled — then change exactly one thing (seed, wording, a LoRA strength) and run again.
  • Collaborate or teach. Two machines with the same models installed can pass a single output file back and forth and both have the complete recipe. For classrooms or chat apps that strip images, the Recipe bundle sends the same thing as text: a readable recipe.txt checklist plus the workflow JSON.
  • Learn from other people's work. An original ComfyUI output from a colleague or a Civitai Download shows their real prompt and settings — including which custom node packs you would need before their graph will run.
What this can and cannot do — read first
  • It only works on the original file. Metadata lives in the file's bytes, not its pixels. Copy-paste of an image, screenshots, Discord/Reddit/X/Instagram/messenger uploads, and the displayed image on Civitai all re-encode and lose it. Moving or zipping the file keeps it; on Civitai only the post's Download button does.
  • Nothing is stored if the creator turned it off. ComfyUI's --disable-metadata (Desktop: "Disable saving prompt metadata in files") writes no recipe at all. Preview Image never writes files. Some custom save nodes have their own toggle.
  • The recipe is not the ingredients. You get model, LoRA and input filenames — never the weights, the input image's pixels, or the custom node packs. To reproduce a result you need the same files under the same names. LoRA trigger words are not stored anywhere unless they were typed into the prompt.
  • Reconstruction is best-effort. Positive/negative labels, sampler settings and model family are inferred from the graph. Core nodes are reliable; unusual custom nodes or graphs saved without the API prompt field may show gaps or raw widget lists. The raw JSON at the bottom is always the ground truth.
  • It proves nothing. Embedded metadata is plain editable text — a recipe, not a signature. It cannot tell you who made a file or whether it was altered.
Where the data lives. ComfyUI's built-in save nodes write two JSON blobs unless the server runs with --disable-metadata: prompt (the executed API graph — every node's inputs, so prompt text, model filenames, LoRA names and strengths, seed, steps, CFG, sampler, sizes) and workflow (the full canvas: same values plus layout, links, notes and subgraphs — the file ComfyUI reloads when you drag an image onto it). PNG keeps them in tEXt chunks, animated WebP in EXIF tags, MP4/WebM as container tags, .latent/.safetensors in the header. Typical size: 10–60 KB per output.
Why a file can come up empty. Anything that re-encodes strips it: Discord, Reddit, X, Instagram, messengers, screenshots, most image editors — and the displayed image on Civitai (a CDN transform). On Civitai use the post's Download button, which fetches the uploader's original; right-click → Save image does not. Direct file hosts (Catbox, HuggingFace, GitHub, Drive) keep it. And the uploader may simply have had metadata disabled.
Trust. Embedded metadata is plain text anyone can edit. It is a recipe, not a signature — it proves nothing about who made the file.
